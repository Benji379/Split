Split: imprime una imagen en varias hojas y arma tu póster

1 Imagen y texto

    Aún no hay imágenes.

    Cada imagen que cargues o pegues se añade como una capa nueva. Arrastra las capas para cambiar cuál queda encima; clic derecho sobre una imagen para ordenarla, Supr para eliminarla.

    2 Hojas

    La franja gris de cada hoja es para el pegamento: recorta el margen izquierdo/superior de la hoja siguiente y pégala encima.

    3 Ajuste de la imagen

    Arrastra la imagen para moverla, usa las esquinas para cambiar su tamaño o la rueda del mouse para hacer zoom.
